# Praktikum Pemrograman Web - Pertemuan 2: Elemen Dasar HTML

Repositori ini berisi dokumentasi dan hasil pengerjaan praktikum mengenai **Elemen-elemen HTML**. Tujuan utama dari praktikum ini adalah untuk memahami cara membangun struktur halaman web yang solid dengan menggunakan berbagai tag fundamental.

## 📝 Deskripsi Tugas
Praktikum ini mencakup penguasaan elemen dasar yang menjadi pondasi dalam pengembangan web, antara lain:

* **Implementasi Tag HTML:** Memahami penggunaan tag berpasangan dan *void elements* untuk membentuk kerangka dokumen.
* **Manajemen Jalur File (Path):** Menerapkan konsep *Relative Path* untuk menghubungkan aset lokal dan *Absolute Path* untuk referensi sumber eksternal.
* **Sistem Navigasi:** Membangun keterhubungan antar-halaman web melalui elemen hyperlink (`<a>`).
* **Integrasi Multimedia:** Menyajikan konten visual yang interaktif menggunakan elemen gambar (`<img>`) serta video (lokal dan *embed* YouTube).
* **Strukturisasi Data:** Mengorganisir informasi secara rapi dan profesional menggunakan elemen Tabel (`<table>`) dan List (`<ul>` & `<ol>`).

---

## 🚀 Studi Kasus: Halaman Detail Film
Sebagai tugas utama (challenge), saya mengimplementasikan seluruh materi tersebut ke dalam sebuah **Halaman Detail Film**. Studi kasus ini dirancang untuk menampilkan informasi film secara terperinci dengan spesifikasi:

1.  **Identitas Visual:** Menampilkan poster film yang didukung dengan informasi judul yang jelas.
2.  **Detail Informatif:** Menyusun data teknis seperti Tahun Rilis, Sutradara, Studio, dan Rating dalam format tabel agar mudah dipahami.
3.  **Daftar Karakter & Fakta:** Mengelola daftar pemeran menggunakan *Unordered List* dan urutan informasi menarik lainnya menggunakan *Ordered List*.
4.  **Konten Trailer:** Menyematkan video trailer resmi untuk memberikan pengalaman multimedia yang utuh bagi pengguna.
5.  **Interaktivitas:** Menyediakan navigasi untuk mempermudah transisi antar-halaman dalam situs web.
